# Number Guessing Game 🎯

A simple Python game where the player tries to guess a randomly generated number between 1 and 100.

## 🚀 Features
- Random number generation
- User-friendly command-line gameplay
- Hints for high or low guesses
- Unlimited attempts until correct guess

## 🛠️ Tech Stack
- Python
- Random Module

## ▶️ Run Project

```bash
python main.py
```

## ⚙️ How It Works

Computer generates a random number → User enters guess → Program gives hints → Game continues until correct guess
